## User Request

### Requested result
Add a UI to mutastic as a Windows taskbar tray icon: clicking the icon brings up a UI, developed end-to-end with the-usual workflow after discarding ("nixing") the previous direct-implementation attempt.

### Explicit constraints
- The tray UI runs on the Windows side (native Windows process), not under WSL.
- The tray offers a single Quit action that stops the daemon (daemon-quitting Quit, not a tray-only quit).
- Develop via the-usual workflow; the earlier directly-implemented version is discarded.

### Accepted tradeoffs and residuals
- The previous implementation's uncommitted changes were reverted and the clean tree re-verified (build + tests green); nothing was kept from it.

**Goal:** A resident Windows notification-area icon shows the true mic mute state at a glance, left-click brings up the existing light-panel UI, right-click offers mute/light quick actions, and Quit stops both the daemon and the tray in one click.

**Architecture:** Add a `shutdown` verb to the daemon's UDP command surface (`127.0.0.1:42814`): the reply is written before the daemon's context is cancelled, so callers always get their ack. Add a `mutastic tray` subcommand — a pure UDP client holding no hardware (same pattern as the deck plugin) — using `github.com/energye/systray` for the icon, menu, and click callbacks. All daemon-derived display decisions live in a platform-neutral mapping file so they are unit-testable on Linux; the systray glue compiles Windows-only. Clicking the icon opens the existing loopback web panel (`127.0.0.1:42815`) via the existing `openBrowser`.

**Tech Stack:** Go 1.26.3 (windows/amd64 cross-built from WSL via `build.sh`, CGO + mingw already required by `go-hid`), `github.com/energye/systray` v1.0.3 (pure-syscall Win32 backend — needs no C code itself), existing UDP command surface (`deckplugin.go` `askDaemon`), Pillow + rsvg-convert icon generation (`deck/icons/gen-mdi-icons.py`), Go `//go:embed` for icon assets.

### Task 1: Daemon `shutdown` verb + `mutastic shutdown` client command

The tray's Quit needs a way to stop the daemon; today the only exits are taskkill/logoff. The daemon replies `shutting down`, and only AFTER the reply is on the wire fires a `Shutdown` hook that cancels the daemon context — cancelling inside `HandleCommand` would race the send, because `Run`'s ctx-watcher goroutine closes `pc`. The context cancel also cleanly stops the light manager: `MultiManager.Run(ctx)` (internal/light/multi.go:97) drains all per-light sessions on `ctx.Done()` (bounded, ~2 s/light worst case) and all persistence is write-time, so no extra teardown work exists anywhere.

	pc, err := net.ListenPacket("udp", "127.0.0.1:0")
	if err != nil {
		t.Fatal(err)
	}
	open := func() (Device, error) { return newFakeDevice(), nil }
	ctx, cancel := context.WithCancel(context.Background())
	done := make(chan struct{})
	go func() {
		Run(ctx, open, nil, nil, cancel, pc, testLogger())
		close(done)
	}()
	addr := pc.LocalAddr().String()
	conn, err := net.Dial("udp", addr)
	if err != nil {
		t.Fatal(err)
	}
	defer conn.Close()
	conn.SetDeadline(time.Now().Add(2 * time.Second))
	if _, err := conn.Write([]byte("shutdown")); err != nil {
		t.Fatal(err)
	}
	buf := make([]byte, 256)
	n, err := conn.Read(buf)
	if err != nil {
		t.Fatalf("no reply to shutdown: %v", err)
	}
	// The ack must arrive even though the daemon is tearing itself down:
	// the tray's Quit treats a missing reply as "daemon unreachable".
	if got := string(buf[:n]); got != "shutting down" {
		t.Fatalf("shutdown reply = %q, want %q", got, "shutting down")
	}
	select {
	case <-done:
	case <-time.After(2 * time.Second):
		t.Fatal("Run did not return after the shutdown command")
	}
}
```

// Run serves UDP commands on pc and maintains the device session until ctx

func Run(ctx context.Context, open OpenFunc, light CommandHandler, inject KeyInjector, shutdown func(), pc net.PacketConn, logger *log.Logger) error {
	d := New(logger)
	d.Light = light

package main

// trayState is the collapsed tray display state derived from one daemon
// "status" round trip. It maps the daemon's replies ("muted", "unmuted",
// "unknown") plus the transport failure case ("down") onto everything the
// systray glue (Windows) needs, so the display decisions are unit-testable
// on Linux. All functions are pure.
type trayState int

const (
	trayStateDown trayState = iota
	trayStateMuted
	trayStateUnmuted
	trayStateUnknown
)

// trayStateFor collapses one status round trip into a display state. Any
// transport failure is "down" (the daemon's UDP port doubles as its liveness
// signal); any non-error reply other than a definitive state - including the
// daemon's literal "unknown" - keeps the mic-state-unknown display rather
// than pretending the daemon is gone.
func trayStateFor(reply string, err error) trayState {
	if err != nil {
		return trayStateDown
	}
	switch reply {
	case "muted":
		return trayStateMuted
	case "unmuted":
		return trayStateUnmuted
	default:
		return trayStateUnknown
	}
}

// trayTitle is the status line shown as the disabled menu header and the
// icon tooltip.
func trayTitle(s trayState) string {
	switch s {
	case trayStateMuted:
		return "Mutastic — muted"
	case trayStateUnmuted:
		return "Mutastic — live"
	case trayStateUnknown:
		return "Mutastic — mic state unknown"
	default:
		return "Mutastic — daemon unreachable"
	}
}

// trayMutedChecked reports the Muted menu item's check state.
func trayMutedChecked(s trayState) bool { return s == trayStateMuted }

// trayActionsEnabled reports whether mic/light menu actions are usable;
// they are all daemon round trips, so a dead daemon disables them (the
// Light panel and Quit items stay enabled: the panel is served by the
// separate `mutastic ui` process, and Quit must always work).
func trayActionsEnabled(s trayState) bool { return s != trayStateDown }
```

//go:build windows

package main

import (
	_ "embed"
	"fmt"
	"net"
	"time"

	"github.com/energye/systray"
)

//go:embed deck/icons/tray-mic.ico
var trayIconLive []byte

//go:embed deck/icons/tray-mic-muted.ico
var trayIconMuted []byte

const (
	// trayPanelURL is the light controller served by `mutastic ui`
	// (ui.go); left-clicking the tray icon opens it.
	trayPanelURL = "http://127.0.0.1:42815/"
	// trayInstanceAddr is a loopback TCP listen that doubles as the tray's
	// single-instance lock - the same trick as the daemon's UDP bind.
	trayInstanceAddr = "127.0.0.1:42816"
	trayPollEvery    = 2 * time.Second
)

// runTray puts the mutastic icon in the notification area and blocks in the
// systray message loop until Quit. The tray is a pure CLIENT of the daemon
// (UDP, like the deck plugin): it owns no hardware, so quitting - or
// crashing - leaves the mute path intact.
func runTray() int {
	hideConsoleIfOwned()
	lock, err := net.Listen("tcp", trayInstanceAddr)
	if err != nil {
		// Another tray process owns the icon; a second one adds nothing.
		return 1
	}
	defer lock.Close()
	systray.Run(trayOnReady, func() {})
	return 0
}

func trayOnReady() {
	systray.SetIcon(trayIconLive)
	systray.SetTooltip("Mutastic")
	// Left click opens the light panel; right click shows the menu. The
	// fork's default is "menu hidden once handlers are set", so ask for it
	// explicitly.
	systray.SetOnClick(func(systray.IMenu) { _ = openBrowser(trayPanelURL) })
	systray.SetOnRClick(func(m systray.IMenu) { _ = m.ShowMenu() })

	header := systray.AddMenuItem("Mutastic", "daemon status")
	header.Disable()
	systray.AddSeparator()

	muted := systray.AddMenuItemCheckbox("Muted", "toggle the Yeti X hardware mute", false)
	systray.AddSeparator()

	lights := systray.AddMenuItem("Toggle lights", "if any light is on, turn all off; otherwise turn all on")
	brightness := systray.AddMenuItem("Brightness", "set brightness on all lights")
	preset := systray.AddMenuItem("Light preset", "apply a preset on all lights")

	systray.AddSeparator()
	panel := systray.AddMenuItem("Light panel…", "open the full light controller in the browser")
	quit := systray.AddMenuItem("Quit", "stop the mutastic daemon and exit")

	// All tray-visible state is refreshed by one goroutine fed by refreshCh:
	// the ticker and the menu handlers only signal. (systray methods may be
	// called from any goroutine; the serialization protects OUR last-known
	// state, not the library.)
	refreshCh := make(chan struct{}, 1)
	signalRefresh := func() {
		select {
		case refreshCh <- struct{}{}:
		default:
		}
	}

	muted.Click(func() {
		go func() {
			_, _ = askDaemon("toggle", udpAddr, time.Second)
			// The daemon applies the state change before replying, so the
			// refresh observes the new mute state.
			signalRefresh()
		}()
	})
	// Light actions are fire-and-forget in background goroutines: a wedged
	// light can stall a reply for lightClientTimeout, which must not freeze
	// menu dispatch.
	lightCmd := func(command string) func() {
		return func() { go func() { _, _ = askDaemon(command, udpAddr, lightClientTimeout) }() }
	}
	lights.Click(lightCmd("light toggle"))
	for _, pct := range []int{10, 25, 50, 75, 100} {
		brightness.AddSubMenuItem(fmt.Sprintf("%d%%", pct), "").Click(lightCmd(fmt.Sprintf("light brightness %d", pct)))
	}
	for _, name := range []string{"cold", "sunlight", "afternoon", "sunset", "candle"} {
		preset.AddSubMenuItem(name, "").Click(lightCmd("light preset "+name))
	}
	panel.Click(func() { go func() { _ = openBrowser(trayPanelURL) }() })
	quit.Click(func() {
		go func() {
			// Best effort: Quit must close the tray even when the daemon is
			// already gone (or its ack was lost).
			_, _ = askDaemon("shutdown", udpAddr, time.Second)
			systray.Quit()
		}()
	})

	go trayRefreshLoop(refreshCh, header, muted, lights, brightness, preset)
	go func() {
		for range time.Tick(trayPollEvery) {
			signalRefresh()
		}
	}()
	signalRefresh()
}

// trayRefreshLoop owns all tray-visible state. Each signal triggers one
// daemon status round trip; every display decision comes from the pure
// traystate.go mapping, and updates are applied only on state transitions,
// so the native calls happen exactly when the display flaps.
func trayRefreshLoop(refreshCh <-chan struct{}, header, muted, lights, brightness, preset *systray.MenuItem) {
	first := true
	last := trayStateUnknown
	for range refreshCh {
		reply, err := askDaemon("status", udpAddr, time.Second)
		state := trayStateFor(reply, err)
		if !first && state == last {
			continue
		}
		first = false
		last = state
		if state == trayStateMuted {
			systray.SetIcon(trayIconMuted)
		} else {
			systray.SetIcon(trayIconLive)
		}
		systray.SetTooltip(trayTitle(state))
		header.SetTitle(trayTitle(state))
		if trayMutedChecked(state) {
			muted.Check()
		} else {
			muted.Uncheck()
		}
		enabled := trayActionsEnabled(state)
		for _, it := range []*systray.MenuItem{muted, lights, brightness, preset} {
			if enabled {
				it.Enable()
			} else {
				it.Disable()
			}
		}
	}
}
